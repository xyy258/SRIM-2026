## Why this folder exists                                          (2026-08-28)

# Two LES of the same physics, run by two people: Stokes, an oscillating tidal
# bottom boundary layer (Stokes/3D), and Ekman, a steady rotating one (Ekman/).
# Both sweep the initial buoyancy profile and ask what sets the mixing in the
# bottom mixed layer. omega = f0 = 1e-4 deliberately, so r = N/omega = N/f means
# the same background N on both sides.
#
# *** Standing rule: work in Combined/. Do not change any code in Ekman/.
#     Anything that needs changing gets copied here first. *** Ekman/ is the
# collaborator's. Nothing here reads code from it, only .jld2 data under Data/.
# `git status --porcelain Ekman/` returns nothing and should keep doing so.
#
# Run everything with --project=. from inside Combined/.


## What is measured                                                (2026-08-30)

# All at z = h, the mixed-layer top (crossing definition at 0.1 N2_ref), and
# reduced to one number per case by a median over time.
#
#   TKE       from the plane-averaged second moments
#   F_b       <w'b'> + F_sgs, the whole buoyancy flux
#   K_T       -F_b / <db/dz>
#   l = L_K   K_T/sqrt(TKE), the mixing length
#
# Two rules applied everywhere, and they matter more than they look:
#   1. Boxcar in time over one twentieth of a forcing period BEFORE any ratio.
#   2. Per sample first, median second. Never median/median.
# A gradient floor of 0.05 N2_ref guards the K_T division.


## The two asymmetries, and the re-run that closed them   (2026-08-30 → 09-05)

# The first comparison put l against sqrt(TKE)/N for both flows and the Ekman
# points missed the Stokes curve. Two reasons, neither physics: Ekman 3D.jl
# wrote no subgrid buoyancy flux, and its averages were a single y-slice.
# Neither is fixable offline, so Combined/ekmanrun.jl re-ran the seven-case
# T = 10 m column with full-plane moments including F_sgs, including
# Ekman/3D Simulation/Parameters.jl rather than copying it.
#
# The first attempt (09-02) failed silently — all seven wrote t = 0, hit NaN at
# iteration 100, and exited 0. Cause: the profile-4 softplus is written as
# log(1 + exp(sharp*(z-T))), which overflows above z = T + 118.3 m; commit
# e278f55 had taken Lz from 100 to 150, pushing the domain top past it. Fixed
# in ekmanrun.jl with max(x,0) + log1p(exp(-|x|)), and the driver now checks the
# moments file reached the stop time before writing a marker.
# *** The overflow is still in Ekman 3D.jl. It is the collaborator's file. ***
#
# The re-run came back clean: 2548 samples a case over 12.73 inertial periods,
# no non-finite values, subgrid closure live everywhere. The result it existed
# to get — the subgrid share of K_T at z = h:
#
#   r          0.5   1     2     5     10    25    50
#   Ekman     0.04  0.05  0.06  0.10  0.17  0.32  0.56
#   Stokes      —   0.03  0.03  0.06  0.10  0.30  0.59
#
# Two different flows, the same share as a function of stratification. Reading
# the old resolved-only Ekman K_T against the full Stokes curve had understated

#
# Geometry note: the new column is Lz = 150, Nz = 400, t_end 8e5 s; the old

## Shear, and the combined length scale                    (2026-09-05 → 09-06)

# Two scales from the same TKE at the same height, plus the mixing length:
#
#   L_N = sqrt(TKE)/N     L_s = sqrt(TKE)/S     L_K = K_T/sqrt(TKE)
#
# S is the MEAN shear, |d<u_h>/dz| = sqrt((dU/dz)^2 + (dV/dz)^2), differenced
# from the stored plane-averaged U and V on the faces, both components kept.
# Neither pipeline had stored it.
#
# L_N is the smaller scale nearly everywhere — the one exception in thirteen
# cases is Stokes r = 1 at L_s/L_N = 0.74. So these runs are stratification-
# limited, and the shear-limited regime lies below r = 1 on the Stokes side and
# is never reached on the Ekman side. L_s/L_N climbs 0.74 to 15.6 for Stokes but
# is flat near 3 for Ekman: in the rotating runs the two scale together.
#
# tau_K = K_T/TKE follows tau_N = 1/N closely and the flows nearly collapse
# (exponents 0.81 and 0.86); against tau_s = 1/S they separate (2.30 and 0.94).
#
# Seven weighted combinations were tried. Two results:
#   *** No combination makes L_K proportional to L_c. *** Best b = 1 fit is
#   17.2 %, and every candidate keeps a natural exponent near 0.9.
#   *** But combining unifies the flows, with the saturating form kept. *** One
#   curve through all thirteen goes from 14.9 % on L_N alone to 10.2 % (min) and
#   10.4 % (equal-weight harmonic), against 7.5 % for a single flow alone.
#
# The equal-weight harmonic 1/L_harm = 1/L_N + 1/L_s is the one to prefer: ties
# the minimum, smooth rather than kinked, no free parameter. The tuned variants
# are worse on the saturating fit despite having one.
#
# Caution: L_harm is a monotone function of L_N and L_s, so some improvement is
# expected with six or seven points. And the candidates are near-degenerate over
# most of the data — nearly all the discrimination comes from the Stokes
# sequence, where L_s/L_N sweeps a factor of 20.
#
# The summary figure (L_K_vs_Lharm_T10.png) adds the regime question: w_s =
# L_harm/L_s is the shear's share of 1/L_harm, and w_s > 1/2 means shear-
# limited. Exactly one case of thirteen is, Stokes r = 1 at 0.59. Stokes marches
# 0.59 -> 0.06 as N rises; Ekman sits at 0.22-0.26 throughout.


## The Corrsin shear scale                                         (2026-09-06)

# L_C = (eps/S^3)^(1/2), the shear analogue of the Ozmidov scale.
#
# *** Neither pipeline stored eps, and it cannot be rebuilt from stored
# averages. *** It was taken instead from the TKE budget under local
# equilibrium, eps ~ P + B, every other term of which is on disk. Transport is
# dropped and cannot be checked; storage is dropped and can be; nu_e ~ kappa_e.
#
# The estimate is sound everywhere inside the layer and *fails at z = h itself*,
# for the strongly stratified Stokes cases — fraction of samples with eps > 0 is
# 0.83-1.00 at 0.25-0.75h but falls to 0.03 at z = h for Stokes r = 50. The
# reason is in the terms: P ~ 0 there, so the budget at the mixed-layer top is
# transport against buoyancy destruction, which is what local equilibrium
# discards. A statement about the height, not the method. Worth remembering for
# anything else evaluated at z = h.
#
# Three cases are unusable (Stokes r = 10, 25, 50), drawn hollow and excluded.
# Of the ten that stand:
#
#   Ekman,   7 cases   l = 0.331 L_C^0.92   rms 12.4 %
#   Stokes,  3 cases   l = 0.874 L_C^2.19   rms 10.9 %
#   overall 10 cases   l = 0.375 L_C^0.89   rms 25.7 %
#
# *** The Ekman column is close to l ~ L_C/3 across a factor of thirty. *** That
# is cleaner than sqrt(TKE)/N ever gave on that side. The flows do not share it,
# but the Stokes fit is three points over less than a factor of two in L_C,
# exactly where the eps estimate starts to degrade — the weakest number here.

## The delta model, three stages                                   (2026-09-09)

# Testing TKE(z) = A1 exp(-A2 z/delta) and
#         K_T = B1 delta sqrt(TKE) (B2 + exp(B3 L_harm/delta)).
# Divided by sqrt(TKE) the second is the saturating form already fitted, with
# one new claim: that the plateau and the knee both scale with a thickness
# rather than being fitted per flow.
#
# u_* was MEASURED, as max over 0 < z <= h of the total stress, not assumed. It
# is flat to under 3 % across each sweep, and the free-stream estimate
# sqrt(c_D)U_inf is 4x too large for Stokes — every delta would have been 4x too
# big had it been assumed.
#
# --- Stage 1, which delta tracks h: WORKS ---
#
#     h = 1.05 u_*/omega (1 + N^2/omega^2)^(-0.040)   flat to 1.6 %   tidal
#     h = 0.85 u_*/f     (1 + N^2/f^2)^(-0.155)       flat to 4.4 %   rotating
#
# The tidal layer is almost stratification-blind: its thickness is set by omega
# and N gets no time to act. Weatherly & Martin's exponent 1/4 is too steep for
# the rotating column (though the unequilibrated low-N/f cases make 0.155 a
# lower bound). The published constants 0.4 and 1.3 are NOT mutually calibrated
# — they put h/delta at 2.62 and 0.66.
#
# --- Stage 2, is TKE exponential: HALF WORKS ---
#
# The six Stokes profiles collapse onto one exponential with no stratification
# dependence at all, A1/u_*^2 = 3.4 to 3 %. The Ekman profiles do NOT collapse:
# they fan out by x1.6 in decay rate and flatten to a floor above z ~ h.
# *** h/delta being flat does not imply the profiles collapse on delta. ***
# Fitted from the TKE peak to z = h, never from the wall.
#
# --- Stage 3, the K_T model: DOES NOT WORK ---
#
#   delta                        both   Stokes   Ekman
#   published (0.4, 1.3)        18.1 %   9.1 %   7.9 %
#   one common constant         12.0 %   9.1 %   7.9 %
#   delta = h, most favourable  11.1 %   9.1 %   8.2 %
#   unscaled, no delta at all   10.4 %   9.1 %   8.9 %
#
# No thickness improves the two-flow collapse; delta = h is the best case and
# still loses to not scaling. The Stokes column cannot test this — its largest
# L_harm is 0.23 x0, so it never reaches the bend. The initial slopes do agree,
# 0.451 against 0.454, but that quantity contains no delta and is evidence for
# L_harm, not for the thickness.
#
# Keep the h law from stage 1. Keep writing the mixing law without delta, as
# L_K = 2.18(1 - e^(-L_harm/4.89)), rms 10.4 %.

## L_C in place of L_s: the regime structure does not survive     (2026-09-16)

# plot_corrsin_scales_T10.jl redoes the L_N/L_s study with the Corrsin scale
# L_C = (eps/S^3)^(1/2) as the shear-side partner. Three figures:
# L_N_L_C_vs_r_T10.png, L_K_vs_Lcomb_corrsin_T10.png, L_K_vs_Lbest_corrsin_T10.png.
# Nothing new is read — L_K, L_N, L_s and L_C all come off the existing
# corrsin_T10.jld2 and ekman_lengthscales_T10_moments.jld2 on one sample basis.
# 13 of 16 cases, the eps>0 rule of plot_l_vs_corrsin_T10.jl.
#
# --- the answer is no, and for two separate reasons ---
#
# 1. L_C IS THE SMALLER SCALE IN EVERY RELIABLE CASE. L_C/L_N runs 0.031 -> 0.997
# in Stokes and 0.216 -> 0.997 -> 0.840 in Ekman, and never crosses 1. The shear
# share w_C = 1/(1 + L_C/L_N) is therefore >= 1/2 everywhere by construction —
# there is no r at which L_N takes over. The only values above 1 are Stokes
# r = 10 (1.13) and r = 50 (1.28), both eps-unusable, and non-monotonic
# (r = 25 falls back to 0.55). That is the eps estimate failing, not a crossing.
# With L_s the crossing is clean, monotonic, and keeps going to x15.6.
#
# 2. THE STOKES COLUMN CANNOT TEST IT. Over r <= 5, where eps is usable, the
# case medians move by L_N x46.0, L_s x1.31, L_C x1.52, L_K x2.9. L_C moves half
# as much as the quantity it is meant to explain, and the eps cut removed
# exactly the three cases where it would have varied (over all eight it is
# x13.8). That is the Stokes cluster sitting off the line in the L_C panel.
#
# --- the fits, for the record ---
#
#   candidate            A     b=1 both   sat both   sat Stokes   sat Ekman
#   L_N alone          0.175     82.0 %     35.2 %       6.8 %       7.1 %
#   L_C alone          0.418     33.5 %     31.0 %      27.1 %      14.9 %
#   min(L_N, L_C)      0.422     32.6 %     29.9 %      25.4 %      13.8 %
#   harmonic, equal    0.643     20.3 %     13.8 %      12.6 %       9.5 %
#   harmonic, weighted 0.591     20.0 %     12.8 %      12.4 %       9.3 %   b = 0.88
#   p-norm             0.729     19.9 %     12.8 %      13.4 %       9.4 %   p = 0.82
#   geometric          0.331     20.9 %     16.9 %      18.7 %      11.0 %   a = 0.25
#
# A = geomean(L_K/L_comb), the constant the black line in each panel is drawn
# with; both candidate figures now print it on the panel (2026-09-16). It says
# where a candidate sits, not how well it collapses. L_C alone gives A = 0.418
# against 0.109 for L_s alone — L_K is ~0.4 L_C but only ~0.1 L_s, so the
# Corrsin scale sits far closer to the mixing length than the shear scale does.
# That is the other half of why it looks better one-on-one.
#
# L_C ALONE IS A BETTER SHEAR SCALE THAN L_s ALONE — 33.5 % against 62.4 % on
# the proportionality, natural exponent 0.88 against 1.03. It carries real
# information. But COMBINED it is worse and on fewer cases: 12.8 % on 13 against
# 10.0 % (min) and 10.8 % (harmonic) on 16. And min(L_N, L_C) at 29.9 % is
# indistinguishable from L_C alone at 31.0 %, which is point 1 restated — the
# minimum is L_C almost everywhere, so taking it buys nothing.
#
# The combination still beats L_N alone (35.2 % -> 12.8 %), so L_C is not
# useless. But the mechanism is REVERSED from the one being tested: L_C is the
# smaller scale everywhere yet nearly flat across Stokes, so it is L_N that
# supplies the variation there. Not "stratification limits at high N, shear at
# low N" — two scales combining well for another reason.
#
# VERDICT: keep L_s. The two-regime idea is well supported, but by sqrt(Ri),
# which has the clean crossing, the interpretation, and the better collapse on
# all 16 cases. L_C stays what it was, an independent check in the Corrsin
# section, not the scale to build the model on.


## Nondimensional K_T* = f(Ri): checked, not yet built        (2026-09-16)

# Proposal: drop the dimensional fits and work with K_T* = K_T N / TKE against
# Ri. It comes straight out of the harmonic law with A = 1,
#     1/L_K = 1/L_N + 1/L_s   =>   TKE/K_T = N + S   =>   K_T* = 1/(1 + S/N)
# and since sqrt(Ri) = N/S in this folder's convention, S/N = 1/sqrt(Ri), so
#     K_T* = sqrt(Ri)/(1 + sqrt(Ri)),  or  A*sqrt(Ri)/(1+sqrt(Ri)) with A free.
# (The proposal as written had S/N = sqrt(Ri), which is inverted and flips both
# limits. With the correct sign: Ri -> inf gives K_T -> TKE/N, stratification-
# limited; Ri -> 0 gives K_T -> TKE/S, shear-limited. Both right.)
#
# K_T* = (K_T/TKE)*N = tau_K/tau_N, the mixing time in buoyancy times — i.e.
# the left panel of tau_K_vs_timescales_T10.png, normalised. No new data needed.
#
# --- IT IS A CHANGE OF VARIABLES, NOT A CHANGE OF MODEL ---
#
# Fitting K_T* = A sqrt(Ri)/(1+sqrt(Ri)) is ALGEBRAICALLY IDENTICAL to fitting
# L_K = A L_harm: the log residuals are the same expression. Measured 24.0 %
# against the 23.1 % of the dimensional proportionality — the gap is only the
# per-sample median convention. So nondimensionalising cannot improve the fit.
# What it does do is make the real cost visible: A was ALREADY dimensionless
# (both sides are lengths). The dimensional constants live in the SATURATING
# form, L_inf = 2.004 m and x0 = 4.498 m, and those have no nondimensional
# expression at all. The choice is 23-24 % with a clean law or 10.7 % with two
# unexplained lengths. That is worth having stated plainly.
#
# --- three findings from testing it on the 16 cases ---
#
# 1. A FREER f BUYS NOTHING. K_T* = A Ri^(m/2)/(1+Ri^(m/2)) with m free gives
#    m = 1.08, rms 23.3 % against 24.0 % at m = 1. Pure power 28.1 %. The
#    harmonic exponent is already the right one; there is no better simple f.
#
# 2. f(Ri) IS NOT UNIVERSAL ACROSS THE TWO FLOWS. Against a common fit the
#    Stokes cases sit at median 1.123 and the Ekman at 0.926, ~21 % apart. At
#    almost identical Ri (Stokes r=5, Ri=10.94, K*=0.331; Ekman r=5, Ri=10.95,
#    K*=0.289) the two differ by 15 %. Something other than Ri is in play.
#    Per flow: Stokes 14.7 %, Ekman 26.2 %.
#
# 3. *** Ri IS NOT AN INDEPENDENT KNOB, AND THE EKMAN COLUMN BARELY SPANS IT. ***
#    Stokes Ri runs 0.0043 to 263 (x61000). Ekman runs 0.44 to 12.8 (x29), and
#    for r = 1..50 — six of its eight cases — Ri sits between 8 and 13 while
#    K_T* moves 0.235 -> 0.375. It is not even monotonic: r = 50 has the LOWEST
#    Ri of that group (8.05) and the HIGHEST K_T* (0.375). The cause is that S
#    is an output, not a control: in the rotating layer S grows with N (S ~ N
#    above r ~ 1), so Ri saturates near 10. Changing r does not change Ri there.
#
# So the tidal column can carry a nondimensional law over five decades of Ri and
# the rotating column cannot carry one at all. That is physics, not analysis —
# no reprocessing fixes it. Giving the Ekman column leverage on Ri means varying
# something that moves S independently of N (U_inf, or the drag), i.e. new runs.
#
# --- if it is built, two things to get right ---
#
# N here is the BACKGROUND r*omega, not the local sqrt(<db/dz>) at z = h, so
# "Ri" is not the gradient Richardson number the Munk-Anderson / Pacanowski-
# Philander / KPP literature means. The local gradient is available (the Ekman
# reduction stores dBdz; the Stokes moments store the gradient too) and using it
# would make the comparison to that literature legitimate.
#
# But BEWARE SELF-CORRELATION. Do NOT recover the gradient as -F_b/K_T: that
# puts K_T on both axes and manufactures the relationship. Even taken from the
# stored gradient, K_T* ~ N and Ri ~ N^2 share N, so some correlation is built
# in. The dimensional L_K vs L_harm plot has the same issue through sqrt(TKE),
# but it is sharper here and should be stated when the figure is made.


## K_T* vs Ri, Stokes: the background form works                (2026-09-16)

# plot_KTstar_Ri_stokes_T10.jl -> figures/KTstar_vs_Ri_stokes_T10.png.
# Stokes only, pure harmonic form with one free constant,
#     K_T* = K_T N/TKE = A sqrt(Ri)/(1 + sqrt(Ri)).
# Left: z = h, background N = r*omega. Right: z = ZFIX = 10 m fixed, local
# N = sqrt(<db/dz>) there, with K_T, TKE and S all taken at the same height.
# The gradient is read from dBdz in the mixing file, NOT from -F_b/K_T, so K_T
# is not on both axes.
#
#   z = h,  background N    A = 0.412   rms 14.7 %   Ri 0.0043 to 263
#   z = 10 m, local N       A = 0.265   rms 26.3 %   Ri 0.0022 to 2467
#
# --- THE BACKGROUND VERSION WORKS ---
#
# 14.7 % on eight cases with ONE dimensionless constant and no length scale
# anywhere, and both asymptotes are populated: the low-Ri cases sit on
# K_T* = A sqrt(Ri) (K_T -> TKE/S, shear-limited) and the high-Ri ones flatten
# onto K_T* = A (K_T -> TKE/N, stratification-limited), with the knee at Ri ~ 1
# where it belongs. Cleanest statement of the two-regime picture so far.
# Worst case r = 2 at +28 %, then r = 0.2 at -26 %; the rest inside 10 %.
#
# Same model as L_K = A L_harm, so 14.7 % is the Stokes-only proportionality
# rms, not an improvement. The gain is interpretive, and it is real.
#
# --- *** A LOCAL Ri CANNOT BE TAKEN AT z = h *** ---
#
# h IS DEFINED as the height where db/dz crosses H_LEVEL = 0.1 of N2_ref
# (mixed_layer_height.jl, H_DEF = crossing). Measured, db/dz at z = h over
# N2_ref is 0.100000 with min = max = median across every sample of every case.
# So N_loc(h) = sqrt(0.1) N_bg exactly, Ri_loc = 0.1 Ri_bg, and a "local" panel
# at z = h is the background panel translated along the 1:1 diagonal — not
# independent data. Hence the fixed height.
#
# --- THE FIXED-HEIGHT VERSION WAS TRIED AND DROPPED ---
#
# At z = 10 m (= T, the pycnocline height) the gradient is free and Ri spans six
# decades, 0.0022 to 2467, but the fit is 26.3 % against 14.7 %. Height scan:
#     9 m 30.2 %   10 m 26.3 %   11 m 36.3 %   12 m 47.2 %   15 m 43.6 %   18 m 43.6 %
# NO FIXED HEIGHT IS A FAIR ONE. Median h runs 8.6 to 11.3 m, so a fixed z is
# inside the layer for some cases and above it for others:
#   - inside (r = 0.5 to 5): the gradient falls under the 0.05 N2_ref mask and
#     K_T is thrown away — retention 31-42 % against 82-100 % at the ends
#   - above (r = 25, 50): S dies, sqrt(Ri) runs away (49.7 at r = 50, 549 by
#     z = 12 m) and K_T* climbs ABOVE the plateau, r = 50 at 1.47x the fit
# The figure is now the background-N panel alone. The fixed-height code is gone;
# the numbers are kept here.
#
# --- WHY THE EKMAN COLUMN CANNOT DO THIS (diagnosed 2026-09-16) ---
#
# S at z = h, fitted over the equilibrated range r >= 1:
#     Stokes  S ~ N^0.281      Ekman  S ~ N^1.018
# Over a x250 change in N, the Stokes S moves x3.3 and the Ekman S moves x58.
# Since Ri = (N/S)^2 ~ N^(2(1-p)), that is Ri ~ N^1.44 for Stokes and N^(-0.04)
# for Ekman — pinned.
#
# The reason is that the TIDAL LAYER HAS AN EXTERNALLY IMPOSED CLOCK and the
# ROTATING LAYER DOES NOT. h = 1.05 u_*/omega (1+N^2/omega^2)^(-0.020) is almost
# stratification-blind: omega sets the thickness and N gets no time to act, so S
# stays put and Ri tracks N. The steady rotating layer has no such clock, so it
# equilibrates — and equilibration means adjusting until Ri at the layer top
# reaches a marginal value, here about 10. It is self-regulation, not a defect
# in the data.
#
# A z-SCAN DOES WIDEN Ekman's Ri RANGE — BUILT 2026-09-16, see below — but only
# at the top end. Median
# sqrt(Ri) = N/S(z) against height, with the fraction of samples where db/dz
# clears the 0.05 N2_ref mask (so K_T exists at all):
#     r = 0.2   z = 2-10 m: sqrt(Ri) 0.01-0.06, 0 % usable;  z = 25 m: 1.21, 100 %
#     r = 50    z = 2-6 m:  sqrt(Ri) 1.2-2.7,   0 % usable;  z = 25 m: 1075, 100 %
# Inside the mixed layer Ri IS small — which is the regime wanted — but there is
# no gradient there, so K_T = -F_b/<db/dz> does not exist. Everywhere K_T exists,
# Ri is already large. Accessible range is roughly Ri 0.14 to 1e6, all of it on
# the stratification-limited side. THE SHEAR-LIMITED LIMB THAT MAKES THE STOKES
# FIGURE WORK IS NOT REACHABLE IN THE EKMAN COLUMN BY REPROCESSING.

# --- what still stands ---
#
# Stokes spans Ri over five decades on the background N (x61000), which is why
# the Stokes-only version works at all; the Ekman column is pinned near Ri ~ 10
# (previous entry) and was left out deliberately. Self-correlation is noted on
# the figure: K_T* ~ N and Ri ~ N^2 share N, exactly as L_K vs L_harm shares
# sqrt(TKE).


## The height scan: range yes, universality no                   (2026-09-16)

# plot_KTstar_Ri_zscan_T10.jl -> figures/KTstar_vs_Ri_zscan_T10.png.
# One point per (case, height) instead of one per case, everything local:
# N = sqrt(<db/dz>) at z, S at z, K_T and TKE at z. Heights are fractions of
# each case's median h (0.6 to 3.0) so the scan is at the same place in the flow
# for every case. A point is kept only where db/dz clears the 0.05 N2_ref mask

#
#   both     A = 0.217   rms 65.0 %   n = 95   Ri 5.5e-4 to 7.0e6
#   Stokes   A = 0.331   rms 50.3 %   n = 45   Ri 5.5e-4 to 7.0e6
#   Ekman    A = 0.149   rms 52.3 %   n = 50   Ri 8.8e-3 to 4.5e5
#
# THE RANGE PROBLEM IS SOLVED. Ekman goes from Ri 0.44-12.8 at z = h to eight
# decades. So there IS an Ekman version of the figure.
#
# THE PLATEAU IS NOT UNIVERSAL. A = 0.331 for Stokes against 0.149 for Ekman, a
# factor 2.2, and the Ekman points sit visibly below the Stokes ones everywhere.
# Whatever K_T* saturates at, it is not the same number in the two flows.
#
# AND THE COLLAPSE IS MUCH LOOSER: 50-52 % per flow against 14.7 % for the
# Stokes z = h background-N version. The scan buys range by mixing two different
# regions — the turbulent layer interior and the quiescent fluid above it, where
# S has died and Ri runs to 1e5-1e6. Those are not the same physics and the
# saturating form should not be expected to hold across both. At the top end the
# points keep climbing rather than flattening, so the plateau is not clean.
#
# So the z = h background-N Stokes figure stays the headline. This one answers a
# narrower question — can the Ekman column be made to span Ri at all (yes), and
# does it share the Stokes plateau (no).
#
# Still unreachable: the well-mixed interior, where Ri is genuinely small. There
# is no gradient there, so K_T = -F_b/<db/dz> does not exist, and no choice of
# height changes that.

## Mistakes made here, so they are not made again

# - h(t) computed wrongly twice before it was right: a broken findlast returning
#   the top face, then a redo assuming uniform dz on a stretched grid.
# - The unequilibrated Ekman cases were called lower bounds on l. They are upper
#   bounds.
# - A brute-force fit silently returned a grid edge. Every fit here now reports
#   `pinned`, and a pinned fit is never drawn.
# - A dropped-sample diagnostic blamed the shear when every drop was K_T <= 0.
# - Figure lines merged the two flows into one apparent trend. Convention since:
#   line COLOUR says which flow, line STYLE says which quantity.
# - `head` on a Julia pipeline SIGPIPE-kills it before it writes its figures.
# - @sprintf will not take a format string built with `*`.
# - "Use the local gradient Richardson number" was recommended without checking
#   what defines the evaluation height. h is the 0.1 N2_ref gradient crossing,
#   so the local gradient there is fixed by construction and the local Ri is the
#   background one times 0.1. Check what a diagnostic height is defined by
#   before proposing to measure a gradient at it.
# - Two figures were read as showing the low-N cases pinned against the
#   pycnocline, and a caveat written from that, without checking the rest of the
#   sweep for the same thing. It does it too, harder. Look at the comparison
#   before calling a feature special.
# - A reference number ("the unscaled fit is 10.4 %") was copied from one script
#   into another as a literal. It went stale the moment the sweep changed.
#   Numbers that appear in two places get computed in both.
